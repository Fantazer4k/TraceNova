TRACE NOVA — РЕЕСТР ПРОБЛЕМ И ИСПРАВЛЕНИЙ

База: GitHub main 633526f. Ветка: repair/main-security.
Статусы: ОТКРЫТО, ЧАСТИЧНО, ИСПРАВЛЕНО В ВЕТКЕ, ПРОВЕРЕНО В PR.
Для новой записи указывайте приоритет, компонент, наблюдаемый результат,
следующий шаг и критерий проверки. Используйте синтетические данные.
Подробный backlog, зависимости и критерии релиза: DELIVERY_PLAN.md.

P0 / ЧАСТИЧНО / S1 — Доступ и нагрузка
  Локальная привязка по умолчанию и HOST/PORT исправлены. Добавлен
  лимит параллельных анализов на воркер с HTTP 503 при перегрузке.
  Для внешней публикации остаются аутентификация, клиентские квоты и
  проверка ограничений на шлюзе, включая лимит тела запроса.
  Приёмка: закрытый доступ, 429 за квоту, освобождение слота после ошибки.

P0 / ИСПРАВЛЕНО В ВЕТКЕ / S2 — Приватность приложения
  POST уже был в main. Добавлены no-store, общая ошибка валидации без
  отражения входного значения и журналирование класса исключения.
  Журналы и телеметрия внешнего шлюза проверяются при развёртывании.

P0 / ЧАСТИЧНО / S3 — Зависимости
  Обновлены FastAPI, Starlette, aiohttp и python-dotenv (PYSEC-2026-2270).
  Убраны пакеты, для которых в исходниках не обнаружены импорты.
  pip-audit 2.10.1 не нашёл известных уязвимостей в чистой локальной
  установке Python 3.13.13. R1 подтвердил матрицу Windows и Ubuntu
  для Python 3.10/3.13 на коммите 527aea7. Для новых правок нужен
  повторный прогон GitHub Actions.

P1 / ЧАСТИЧНО / S4 — Заголовки и интерфейс
  Главная страница получила CSP и защиту от встраивания. Добавлены
  no-referrer и nosniff, отключены CORS credentials. Справка использует
  нативный диалог с возвратом фокуса. Анимация остановлена при
  reduced motion и в скрытой вкладке. Обновлены версии статических
  файлов, чтобы браузер загрузил совместимые HTML, JS и CSS.
  U1/U2: форма отправляется клавишей Enter, показывает пустой ввод,
  загрузку и ошибку. Смена режима отменяет запрос и очищает результат.
  Карточки отделяют частичное покрытие от пустой выдачи и показывают
  статусы источников текстом. Основная тема сохранена.
  Chrome на 320/768/1440 px: форма и справка помещаются, Escape
  возвращает фокус, reduced motion работает. На 320 px исправлено
  горизонтальное переполнение от фонового свечения. С синтетическими
  ответами проверены загрузка, успех, пустая и частичная выдача,
  ошибка 503 и ответ из предыдущего режима. Ошибок CSP не было.
  Firefox, Safari и ручная проверка на физических устройствах открыты.

P1 / ЧАСТИЧНО / S5 — URL, DoH и TLS
  Ограничены размер и форма ответа DoH, исключены специальные адреса,
  отвергается порт 0, восстановлена проверка TLS в legacy. Остаются
  согласование допустимых портов, исходящей политики и таймаутов DNS.
  IP, Domain и URL используют одинаковый критерий публичного unicast.
  Тест с заглушками проверяет, что специальные IP не передаются RDAP
  и провайдеру геолокации.

P1 / ЧАСТИЧНО / F1 — Охват поиска
  IP, Domain и Phone уже реализованы в main. Email показывает отдельные
  статусы источников, Username выделяет ограничение квоты. Открыты
  проверка живых контрактов и унификация статусов всех провайдеров.
  DNS/MX различает NXDOMAIN, null MX, отсутствие MX, найденные записи
  и недоступность источника. Тесты с заглушками проверяют запасной
  резолвер после сбоя или некорректного ответа.

P2 / ОТКРЫТО / Эксплуатация
  Метрики длительности, лимитов и состояния источников без передачи
  идентификаторов, CI на поддерживаемых ОС и проверка сборки перед релизом.
  Actions переведены на релизы, использующие Node.js 24; actionlint
  прошёл. Обновлённую матрицу ещё предстоит подтвердить в GitHub Actions.

P0 / ПРОВЕРЕНО В PR / R1 — Воспроизводимая сборка
  CI расширен до Python 3.10 и 3.13 на Ubuntu и Windows. Для каждого
  окружения предусмотрены pip check, тесты, аудит и артефакт версий.
  Starlette 1.10.0 требует Python 3.11+, поэтому для 3.10 выбран 1.7.0.
  Повторная чистая установка на Windows: Python 3.13.13, 37 тестов.
  Реальный запуск Uvicorn на loopback: /health, / и /static/script.js
  ответили HTTP 200. На Python 3.10.22 установка и pip check прошли,
  20 тестов прошли, два модуля не загрузились: Windows Application
  Control заблокировал DLL pydantic-core. Локальный запуск на 3.10
  не проверен. Полный набор Python 3.10 прошёл в GitHub Actions.
  pip-audit не нашёл известных уязвимостей в чистых окружениях 3.10 и 3.13.
  PR #7: https://github.com/Fantazer4k/TraceNova/pull/7
  CI по PR: https://github.com/Fantazer4k/TraceNova/actions/runs/44973154172
  CI по HEAD 527aea7: https://github.com/Fantazer4k/TraceNova/actions/runs/44973139155
  Оба прогона: 5 из 5 заданий прошли. В PR на каждом из четырёх
  сочетаний Ubuntu/Windows и Python 3.10/3.13 прошли 37 тестов,
  pip check и pip-audit. GitHub сохранил четыре списка версий.
  Фронтенд: проверка синтаксиса двух JS-файлов и рендеринга шести режимов.
  Независимое ревью diff R1 и результатов CI: блокирующих замечаний нет.
  Артефакты отражают фактически установленные версии. Если потребуется
